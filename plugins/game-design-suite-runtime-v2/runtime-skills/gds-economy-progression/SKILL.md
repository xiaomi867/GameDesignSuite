## Workflow

1. Define each resource's role and meaning before adding sinks.
2. Map sources, sinks, stockpiles, gates, conversion paths, and daily/weekly inflow.
3. Define progression milestones, upgrade costs, pacing targets, and replacement cadence.
4. Test early/mid/late-game surplus, scarcity, mandatory taxes, dead currencies, and cross-system coupling.
5. Reject sinks that exist only to consume surplus; require a legitimate player-facing purpose.
6. Validate costs against power delta, expected earning rate, and alternative uses.

Preserve healthy surplus when it has a role. Do not force unrelated base resources into progression costs merely to remove excess currency.
