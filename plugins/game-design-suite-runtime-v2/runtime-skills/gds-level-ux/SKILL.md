## Workflow

1. Define player goal, decision flow, pacing, and expected comprehension at each step.
2. Structure stages/encounters around teaching, testing, escalation, relief, and payoff.
3. Design UI information hierarchy around the decisions the player must make now.
4. Validate navigation depth, state clarity, error prevention, feedback timing, accessibility, and controller/input implications.
5. Tie level rewards and unlocks to progression without using rewards to mask weak encounter structure.

For existing UI/config, distinguish observed behavior from inferred intent. Use actual screenshots, flows, or stage data when available.
